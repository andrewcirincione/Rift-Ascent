Scope and limits
The runtime logs are ppsspp-final.txt, ppsspp-cold.txt, ppsspp-focus.txt and ppsspp-latest.txt; all record the SHA256 above.
Combat/menu/event scenarios use assisted state fixtures at safe frame-entry breakpoints followed by actual controller actions. This is targeted testing, not an unaided whole-game run.
Repeated presentation waits may be skipped; map transitions and the focused victory sequence were observed unskipped. Host fast-forward/frontend frame skipping only affect emulator display cadence; the game's render loop remains active. Speed timing is measured over game render calls, not host wall time.
The representative native drawing benchmark measured 14.5% less host CPU work; this is not a claim about overall PSP frame rate.
Physical PSP hardware and XMB listening were unavailable. Splash audio was decoded and structurally validated; in-game PCM output was checked inside PPSSPP.
