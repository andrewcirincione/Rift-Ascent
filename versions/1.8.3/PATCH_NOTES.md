# Rift Ascent 1.8.3

- Unlocks now uses the same framed tab style as Inventory. The separate Base Relics tab is removed; each of the five tabs lists its base-game items beneath the unlockable collection and shows the base total. Square jumps between the two sections.
- Closing the combat deck returns immediately, without a fade.
- Multi-enemy targeting has a larger, brighter warm-gold marker. Mist Gazer, Mire Oracle and Void Disciple receive a small lighting lift while retaining their existing art and shadows.
- All six newer enemy abilities now have overhead intent icons, including Stone Giant's cleanse and Block intent. Full effect details remain in the log and enemy information.
- Mystery result screens show a single Continue prompt. Directional menu-navigation instructions have been removed. Redundant boss-relic notification text has been cleared.
- Fixed an out-of-range artwork lookup on newer mystery-event results; result and choice screens now share the same bounded artwork mapping.
- Added twelve original enemy designs: three normal enemies and one elite per act. Acts 1–3 now each have thirteen normal species and five distinct elites; later acts mix those pools.
- Audited card rewards, shops, story gifts, mystery choices, transformations and generated offers against character unlock masks. No locked-card offer reproduced in 665,280 automated source checks; permanent acquisition now also rejects a locked custom card. Existing decks are preserved.
- Existing 1.8.2 saves migrate with unlocks, slots, rarity progress and event history intact. The complete soundtrack and splash audio are preserved.

New enemies: Cinder Sexton, Bellback Vermin, Waxbound Acolyte, Pyre Castellan; Saltglass Eel, Silt Reliquary, Rime Cantor, Abyssal Sacristan; Halo Leech, Starved Herald, Throne Husk, Eclipse Justiciar.

Install: replace EBOOT.PBP in PSP/GAME/RIFTASCENT. Keep SAVE.DAT, PROFILE.DAT and every ASCENT18_ACCOUNT / ASCENT18_RUN file.
